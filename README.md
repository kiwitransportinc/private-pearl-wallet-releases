# Private Pearl Wallet — Android downloads

Download the latest signed APK from [Releases](https://github.com/kiwitransportinc/private-pearl-wallet-releases/releases/latest).

Install over your existing Private Pearl Wallet app. **Do not uninstall or clear app data to update.** Keep an offline recovery backup.

Version 0.5.1 and later automatically check this repository and download verified updates. Open Settings → App updates to check manually or install a ready update. Android asks you to approve installation. No GitHub account is needed on your phone.

Automatic checks occur about every 12 hours, subject to Android scheduling, connectivity and battery constraints. Downloads can use mobile data; automatic updates can be disabled in App updates. The app verifies the package name, newer version, checksum and existing signing identity before opening the installer.

This repository contains signed APKs, checksums and public update metadata only. It contains no private keys, wallet data or GitHub credentials.

Independent development wallet, not affiliated with Pearl Research or Kryptex; not independently security audited. Android 10+ and ARM64/x86_64 required.
